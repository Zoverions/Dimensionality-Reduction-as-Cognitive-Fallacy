# Security and data policy

This repository contains research scripts and historical credential-bearing material. A portfolio review identified an IllustrisTNG credential that the owner accepted as a retained risk. Do not describe the repository or its history as secret-clean, and never paste the credential into issues, logs, reports, or pull requests.

Report new vulnerabilities or credential exposures privately through the repository Security tab. Include the affected commit/path and impact without including plaintext secrets or restricted data.

New code must read credentials from the environment, fail clearly when required configuration is missing, and avoid storing credentials in files, notebooks, outputs, or commit messages. Research data must carry source, license/access terms, checksums, transformations, and redistribution constraints.
